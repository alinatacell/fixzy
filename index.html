📖 Tentang Fixzy

Fixzy adalah aplikasi pembukuan khusus konter dan teknisi servis HP. Dirancang agar proses pencatatan transaksi, data pelanggan, status servis, stok sparepart, hingga laporan keuangan menjadi lebih cepat, rapi, dan profesional.

🚀 Fitur Utama

  • ✔ Pembukuan transaksi servis
  • ✔ Data pelanggan
  • ✔ Status perbaikan
  • ✔ Manajemen sparepart
  • ✔ Laporan harian, bulanan, tahunan
  • ✔ Riwayat servis pelanggan
  • ✔ Backup data cloud
  • ✔ Dashboard keuangan

📱 Petunjuk Penggunaan

  1. Masukkan data pelanggan.
  2. Catat kerusakan HP.
  3. Tambahkan sparepart yang digunakan.
  4. Simpan biaya servis.
  5. Update status pengerjaan.
  6. Saat selesai, data otomatis tersimpan pada riwayat.
  7. Lihat laporan keuangan melalui Dashboard.
