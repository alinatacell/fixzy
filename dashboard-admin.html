👷 Upah Karyawan (Otomatis Potong Kasbon)

Aturan Baru FIX:
1. Hadir = 1 teknisi mengerjakan banyak nota di tanggal sama = 1 hari.
2. Upah Bruto = Upah/hari × Hari Hadir.
3. Kasbon Bulan Ini diambil dari collection pengeluaran jenis "Kasbon Karyawan".
4. Sisa Upah = Upah Bruto - Kasbon. Jika kasbon > bruto, sisa 0 (tidak minus).
5. Laba toko tetap hitung upah bruto, bukan sisa, agar tidak double.
